StudyFrog UI mockups

Proposal derived from the UI and UX research report. Static pages, no data: open each file in a browser. Light and dark follow your system setting.

Screens

  • Today and the app shell — the suggested next session, the progress that leads to action, and the rail.
  • Rehearsal card — recall before reveal, one task per screen, keyboard and touch targets.
  • Match debrief — first-try accuracy, delayed retention, confusion pairs and one primary action.

Files

mockup.css holds the shared tokens (OKLCH colours, violet to pink palette, 44 px targets, focus rings, reduced motion). Each page links to it, so a change there updates every mockup.

Checks

  • Every control is a text button or labelled input, with a visible focus ring.
  • No screen has two primary actions.
  • Colour is never the only signal: states also have text, shape or position.
  • Reduced motion removes transitions; nothing on the answer path depends on animation.
