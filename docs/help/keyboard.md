# Keyboard shortcuts

StudyFrog can be used from the keyboard. Rehearsal in particular is built for it: you never need the mouse during a
run.

## During a run

- **Space**: show the answer.
- **1 2 3 4**: rate Again, Hard, Good, Easy.
- **E M D**: mark the item easy, medium or difficult.
- **S**: skip the item.
- **P**: pause or resume. Pausing hides the question and stops the clock.
- **Esc**: stop the run. What you rated so far is saved.

The keys are off while you type an answer (in **Type answers** mode), so typing never triggers them. The keys are
also written on the buttons, for example **Good (3)**. See [[rehearse]].

## Everywhere

- **Alt+Left** and **Alt+Right**: go back and forward through the places you visited. See [[getting-started|Getting started]].
- **Esc**: stop the run, close a menu, or clear the search.
- **Enter** in the search field of the top bar: open the first search result.
- **Tab**: move between controls. **Shift+Tab** moves back.
- **Space** or **Enter** on a focused button: press it.
- **F1**: open help for this screen. See [[help|Using help]].

## On some screens

- **Left** and **Right**: switch between the tabs of a [[stack-page|stack page]] and of [[settings|Settings]].
- **Up** and **Down** on the bar under a Markdown editor: make the editor shorter or taller. See [[item-page]].
- **Left** and **Right** on the grip at the lower left of the Create dialog: make the dialog narrower or wider. See
  [[create-dialog]].

## Without dragging

Everything you can drag also has a button or a menu, so it works from the keyboard and with a screen reader:

- [[board]] cards: **Push**, **Pull**, **Move up** and **Move down**.
- A stack's Board tab: the **Move** menu on each item. A stack's Backlog tab: the button on each item.
- Planned reviews in the [[calendar]]: **Move to another day…**.
- The [[graph]]: **Items as a list**.

See also the [[faq]].
