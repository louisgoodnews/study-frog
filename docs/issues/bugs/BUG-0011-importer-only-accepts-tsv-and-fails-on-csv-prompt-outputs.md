## Context
When users create flashcards using Google Gemini or other external LLMs following StudyFrog's standard prompts, the AI produces a CSV file (`stack,kind,title,front,back,tags`). However, when attempting to import this file into StudyFrog, the importer fails with:
`Could not create the cards: Tab-separated text (front, back, tags): line 1: a card needs a front and a back separated by a tab`
The current registered card importer strictly expects tab-separated values (TSV) and fails on standard CSV outputs.

## Description
Root cause:
In `examples/studyfrog-ext-example/src/tsv.rs` and `crates/studyfrog-app/src/lib.rs`, the only registered card importer is `tab-separated`, which binds to `["tsv", "txt"]` and explicitly splits lines using `line.split('\t')`. When users save AI prompt output as `.csv` or `.txt`, the importer either fails to find an adapter or attempts to parse CSV lines as tab-separated text. Because comma-separated lines contain no tabs, `fields.as_slice()` fails to match `[f, b, ..]` and produces the error on line 1.

Furthermore, while `studyfrog-service` has full CSV parsing logic in `xfer_csv` and `xfer_csv_map`, the stack card import path (`exec_import::import_file` / `studyfrog-ext`) relies solely on the extension importer, which does not handle CSV formats, quoted cells, commas in values, or multi-column prompt headers.

Steps to reproduce:
1. Generate cards using Google Gemini or the standard prompt:
   ```csv
   stack,kind,title,front,back,tags
   psychologie/multivariate-verfahren,card,,Welche Variable wird in Regressionsanalysen als Regressand bezeichnet?,Die abhängige Variable Y.,Regression;Grundbegriffe
   ```
2. Save the output to a file (e.g. `cards.csv` or `cards.tsv`).
3. In StudyFrog, open a stack and open the Import dialog.
4. Choose the file and click "Import cards".
5. Observe error: `Could not create the cards: Tab-separated text (front, back, tags): line 1: a card needs a front and a back separated by a tab`.

Expected behavior:
StudyFrog should automatically detect whether an imported file is CSV or TSV, parse comma-separated fields with quotes and headers (`stack,kind,title,front,back,tags` or `front,back,tags`), and import cards smoothly into the vault.

## Acceptance Criteria
- [x] The file importer detects and accepts both CSV (comma-separated with quotes) and TSV (tab-separated) files seamlessly
- [x] CSV files generated by Google Gemini and StudyFrog standard prompts (with header stack,kind,title,front,back,tags) import without error
- [x] Appropriate delimiter auto-detection and descriptive error reporting are provided when a file has formatting errors

## Design Notes
- Support both comma and tab delimiters in `crates/studyfrog-ext` / `studyfrog_ext_example` or wire `studyfrog-service::xfer_csv` directly into the card import pipeline.
- Handle standard prompt headers (`stack,kind,title,front,back,tags` and `front,back,tags`).
- Handle quoted strings, escaped commas, and semicolons in tags.
- Files to touch: `examples/studyfrog-ext-example/src/tsv.rs` (or add `csv.rs` / unified delimited importer), `crates/studyfrog-ui/src/exec_import.rs`, `crates/studyfrog-ext/src/registry.rs`.
- Release target: version 0.5.0 (Phase M12).
