## Context
Closing the gap between atomic card review and rich document context.

## Description
Provide a 1-click split navigation experience that opens the source PDF alongside any card or note, scrolling instantly to the exact page and highlight box.

## Acceptance Criteria
- [ ] Rehearsal card and note views display 1-click jump button when PDF source anchor exists
- [ ] Clicking jump opens PDF viewer side-by-side, scrolls to page, and highlights coordinates
- [ ] Side-by-side layout smoothly resizes with keyboard shortcuts to dismiss or refocus
