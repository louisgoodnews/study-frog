## Context
The owner tested the 0.3.1 build on 2026-11-03 and listed what to do in 0.4.0: a better Markdown editor, saving and creating, organizing the vault, prompts for AI agents and clearer imports.

## Description
Make writing and organizing in StudyFrog smoother and let the user bring in material, and take prompts out, with fewer surprises.

## Acceptance Criteria
- [x] Writing in the Markdown editor is quicker and nothing is lost: lists continue, tables and macros exist, edits are saved by themselves
- [x] The vault can be organized as folders and files apart from the item view, and a stack is a folder marked as one, whose items can also be referenced from other stacks
- [x] The user can copy or export ready-made prompts for AI agents, and imports say which layouts and formats they read
