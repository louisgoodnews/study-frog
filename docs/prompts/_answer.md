## How to answer
Answer with only the CSV file, in one code block that starts with three backticks and the word csv and ends with three backticks. Write nothing before the block and nothing after it.

If the attached file is not enough (it is missing, empty, unreadable, or not about what was asked), do not guess. Answer with the single line `PROBLEM: ` followed by the reason in one sentence.

Before you answer, check each point and fix the file if one fails:
1. The first row is exactly `stack,kind,title,front,back,tags`.
2. Every row has six cells, and every cell with a comma, a double quote or a line break is in double quotes.
3. Every double quote inside a quoted cell is written twice.
4. `kind` is `card`, `question` or `note` on every row, and `stack` is filled on every row.
5. No `front` is empty, and no `back` of a card or a question is empty.
6. Every item comes from the attached file; nothing is invented.
7. The answer is one code block and nothing else.
