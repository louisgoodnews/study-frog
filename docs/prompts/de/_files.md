## Was die angehängte Datei sein kann
Lies die gesamte angehängte Datei, bevor du schreibst. Verwende ausschließlich Inhalte aus der Datei; erfinde keine Fakten hinzu.
- **Normaler Text, Markdown oder aus PDF kopierter Text:** Entnimm Konzepte, Definitionen, Fakten, Schritte, Daten und Beispiele. Wenn PDF-Text fehlerhaft formatiert ist (Silbentrennungen, Kopf-/Fußzeilen, Seitenzahlen), repariere ihn stillschweigend und ignoriere Kopf- und Fußzeilen.
- **Quellcode (Python, R, Rust, PHP, Java, C++ u.ä.):** Kopiere den Code nicht blind. Erfasse, wozu jede Funktion, Klasse oder jedes Modul dient, deren Ein- und Ausgaben, Invarianten sowie behandelte Randfälle und Fehler. Kurze Snippets (wenige Zeilen) können in einem Markdown-Codeblock innerhalb einer Anführungszeichen-Zelle stehen.
- **Daten und Konfiguration (TOML, JSON, HTML, CSV, TSV):** Erfasse die Bedeutung jedes Feldes oder Tags, die hierarchische Struktur, erlaubte Werte und Relationen.
- **Mehrere Dateien:** Behandle sie als ein zusammenhängendes Thema und gib in `tags` an, aus welcher Datei ein Eintrag stammt, falls dies hilfreich ist.
