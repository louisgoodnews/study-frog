# Zusammenfassung aus einer Datei erstellen

Erstelle strukturierte Notizen und Schlüsselbegriffe aus der angehängten Datei für StudyFrog.

Du erstellst strukturierte Lernnotizen für eine Lern-App. Der Benutzer hat eine Datei angehängt. Fasse die Kernaussagen prägnant zusammen, strukturiere nach Hauptthemen und hebe zentrale Definitionen hervor. Verwende `note` als `kind` in jeder Zeile.
